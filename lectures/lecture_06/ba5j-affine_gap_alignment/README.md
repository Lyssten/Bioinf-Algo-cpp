# Affine Gap Alignment (BA5J)

## Задача

Найти наилучшее глобальное выравнивание двух аминокислотных последовательностей с аффинным штрафом за гэп.

**Вход:** два пептида  
**Выход:** счёт; две выровненные строки

Формат входного файла Rosalind:
```
PRTEINS
PRTWPSEIN
```

**Пример:**
```
Вход:
PRTEINS
PRTWPSEIN

Вывод:
8
PRT---EINS
PRTWPSEIN-
```

Используется матрица BLOSUM62, штраф за открытие гэпа σ=11, за продление ε=1.

## Теория

### Проблема линейного штрафа

При линейном штрафе (каждый символ гэпа стоит одинаково) алгоритм предпочитает много коротких гэпов вместо одного длинного. Биологически это неверно: один длинный делеционный или вставочный блок гораздо вероятнее, чем множество разрозненных.

**Аффинный штраф:** гэп длины k стоит σ + (k−1)·ε, где σ — стоимость открытия, ε — стоимость продления. При σ≫ε длинные гэпы штрафуются мягче.

### Три матрицы DP

Чтобы учесть аффинный штраф, вводятся три матрицы:

| Матрица | Смысл | Последний шаг |
|---------|-------|---------------|
| `lower[i][j]` | лучшее выравнивание с гэпом в v | горизонтальное ребро |
| `upper[i][j]` | лучшее выравнивание с гэпом в w | вертикальное ребро |
| `middle[i][j]` | лучшее выравнивание с совпадением | диагональное ребро |

Переходы:
```
lower[i][j] = max(lower[i][j-1] − ε,   // продление гэпа в v
                  middle[i][j-1] − σ)   // открытие нового гэпа в v
upper[i][j] = max(upper[i-1][j] − ε,   // продление гэпа в w
                  middle[i-1][j] − σ)   // открытие нового гэпа в w
middle[i][j] = max(lower[i][j],
                   upper[i][j],
                   middle[i-1][j-1] + BLOSUM62[v[i]][w[j]])
```

### Матрица BLOSUM62

BLOSUM62 (Blocks Substitution Matrix, порог 62% идентичности) — наиболее популярная матрица для выравнивания белков умеренной степени сходства. Построена статистически из выравниваний консервативных блоков в BLOCKS-базе. Используется в BLAST по умолчанию.

## Применение

**BLAST** при поиске по базам данных использует BLOSUM62 и аффинные гэпы (σ=11, ε=1) — именно те параметры, что реализованы здесь. Это позволяет находить гомологичные белки со вставками/делециями доменов.

**EMBOSS Needle** (глобальное выравнивание Нидлмана–Вунша) с BLOSUM62 и аффинными гэпами применяется для сравнения ортологичных белков из разных организмов.

## Алгоритм

**Идея:** три матрицы позволяют различить «внутри гэпа» и «вне гэпа», что делает продление гэпа дешевле его открытия.

**Псевдокод:**
```
Инициализация:
  lower[0][j] = −σ − (j-1)·ε,  middle[0][j] = lower[0][j]
  upper[i][0] = −σ − (i-1)·ε,  middle[i][0] = upper[i][0]
  middle[0][0] = 0

for i in 1..n, j in 1..m:
  lower[i][j] = max(lower[i][j-1]−ε, middle[i][j-1]−σ)
  upper[i][j] = max(upper[i-1][j]−ε, middle[i-1][j]−σ)
  middle[i][j] = max(lower[i][j], upper[i][j],
                     middle[i-1][j-1] + BLOSUM62[v[i]][w[j]])

Ответ: max(lower[n][m], upper[n][m], middle[n][m])
```

## Реализация на C++

```cpp
// 1. Три матрицы + три матрицы backtrack
std::vector<std::vector<int>> lower(n+1,..),middle(n+1,..),upper(n+1,..);
std::vector<std::vector<int8_t>> backL(..),backM(..),backU(..);

// 2. Переход для lower (гэп в v): из lower (продление) или middle (открытие)
int lFromL = lower[i][j-1] - epsilon;
int lFromM = middle[i][j-1] - sigma;
if (lFromL >= lFromM) { lower[i][j]=lFromL; backL[i][j]=FROM_LOWER; }
else                  { lower[i][j]=lFromM; backL[i][j]=OPEN_LOWER; }

// 3. Backtrack: три состояния — в каком из трёх листов мы сейчас?
int curState = 2; // начинаем в middle
while (i > 0 || j > 0) {
    if (curState == 0) {          // в lower (гэп в v)
        alignV += '-'; alignW += w[j-1]; --j;
        curState = (backL[i][j+1]==FROM_LOWER) ? 0 : 2;
    } else if (curState == 1) {   // в upper (гэп в w)
        alignV += v[i-1]; alignW += '-'; --i;
        curState = (backU[i+1][j]==FROM_UPPER) ? 1 : 2;
    } else {                      // в middle
        if (backM[i][j]==FROM_DIAG) { alignV+=v[i-1]; alignW+=w[j-1]; --i;--j; }
        else if (backM[i][j]==FROM_LOWER) curState = 0;
        else                            curState = 1;
    }
}
```

## Разбор кода

**`int8_t`** для матриц backtrack экономит память: 4 возможных значения (FROM_LOWER, FROM_UPPER, FROM_DIAG, OPEN_LOWER/UPPER) вмещаются в 1 байт вместо 4.

**`NEG_INF = INT_MIN/2`:** защита от переполнения при сложении `NEG_INF + any_value`. Деление на 2 гарантирует, что `NEG_INF - sigma` не переполнит int.

**Три состояния в backtrack:** `curState` — какой из трёх листов мы «читаем» в данный момент. При переходе `OPEN_LOWER` из middle → lower нужно сначала перейти в lower (сменить curState), а потом уже на следующей итерации двигаться влево.

**Инициализация lower[0][j]:** гэп длины j стоит σ+(j−1)·ε. При j=1: −σ. При j=2: −σ−ε. И т.д.

## Запуск

```bash
./ba5j-affine_gap_alignment                              # sample
./ba5j-affine_gap_alignment --input rosalind_ba5j.txt   # Rosalind вход
./ba5j-affine_gap_alignment -i in.txt -o out.txt
```

## Анализ сложности

**Время: O(n·m)** — три вложенных цикла `for i... for j`, каждый с O(1) работой. Втрое медленнее, чем линейный штраф, но асимптотически то же самое.  
**Память: O(n·m)** — шесть матриц (три DP + три backtrack). Узкое место: тройной вложенный цикл в `affineGapAlignment` при больших последовательностях (>10 000 а.к.).
