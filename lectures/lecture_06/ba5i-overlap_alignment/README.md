# Overlap Alignment (BA5I)

## Задача

Найти наилучшее overlap-выравнивание двух строк: суффикс первой совмещается с префиксом второй.

**Вход:** две строки  
**Выход:** счёт; две выровненные подстроки

Формат входного файла Rosalind:
```
PAWHEAE
HEAGAWGHEE
```

**Пример:**
```
Вход:
PAWHEAE
HEAGAWGHEE

Вывод:
1
HEAE
HEAG
```
match=+1, mismatch=-2, indel=-2.

## Теория

### Что такое overlap-выравнивание

Три основных типа выравнивания:

| Тип | Свободные концы | Использование |
|-----|-----------------|---------------|
| Глобальное | нет | сравнение полных белков |
| Локальное | оба конца обеих строк | поиск доменов |
| Overlap | префикс v, суффикс w | сборка геномов |

При сборке генома из коротких чтений (ридов) нужно находить, какие риды перекрываются: суффикс одного рида совпадает с префиксом другого. Это именно overlap-выравнивание.

### Отличие инициализации от глобального DP

Ключевая идея — **свободные** начальные гэпы в строке v (игнорируем префикс v):

| | Глобальное | Overlap |
|-|------------|---------|
| `dp[i][0]` | `−i·σ` | `0` (бесплатно) |
| `dp[0][j]` | `−j·σ` | `−j·σ` (платим за w) |
| Финал | `dp[n][m]` | max `dp[n][j]` по всем j |

Нулевая первая колонка означает: мы можем начать выравнивание с любой строки v без штрафа. Максимум в последней строке означает: можем закончить в любой колонке w (бесплатный суффикс w).

## Применение

**minimap2** (Li H., 2018) — стандартный инструмент выравнивания длинных чтений PacBio/Nanopore. Основа алгоритма — нахождение overlap-выравниваний между ридами. Для генома *Homo sapiens* (3 Гб) minimap2 находит overlap'ы среди миллионов ридов длиной 10–50 кб за минуты.

**Overlap-Layout-Consensus (OLC)** — парадигма сборки геномов, используемая Celera Assembler (2001). Шаг Overlap — именно поиск суффикс-префиксных перекрытий между ридами.

## Алгоритм

**Идея:** заплатить за начало w (dp[0][j] = −j·σ), дать бесплатный старт для v (dp[i][0] = 0), найти максимум в последней строке.

**Псевдокод:**
```
dp[i][0] = 0          для всех i (свободный префикс v)
dp[0][j] = −j·σ       для j > 0 (платим за старт в w)

for i in 1..n, j in 1..m:
    dp[i][j] = max(dp[i-1][j-1] + score(v[i],w[j]),
                   dp[i-1][j] − σ,
                   dp[i][j-1] − σ)

bestJ = argmax(dp[n][j])  // свободный суффикс w
backtrack от (n, bestJ) до j=0
```

## Реализация на C++

```cpp
// 1. Инициализация: свободный префикс v, штрафной старт w
for (int j = 1; j <= m; ++j)
    dp[0][j] = -j * SIGMA;
// dp[i][0] = 0 по умолчанию

// 2. DP
for (int i = 1; i <= n; ++i)
    for (int j = 1; j <= m; ++j)
        dp[i][j] = std::max({dp[i-1][j-1]+score(v[i-1],w[j-1]),
                              dp[i-1][j]-SIGMA,
                              dp[i][j-1]-SIGMA});

// 3. Найти bestJ с >= для предпочтения большего j при равных счётах
int bestScore = dp[n][0], bestJ = 0;
for (int j = 1; j <= m; ++j)
    if (dp[n][j] >= bestScore) { bestScore = dp[n][j]; bestJ = j; }

// 4. Backtrack: свободный префикс v НЕ добавляем в вывод
int i = n, j = bestJ;
while (i > 0 && j > 0) { /* обычный backtrack */ }
while (j > 0) { alignV += '-'; alignW += w[j-1]; --j; } // начало w
// Остаток i (префикс v) — не включаем
```

## Разбор кода

**`>=` в поиске bestJ:** при равных счётах выбираем наибольший j. Это даёт «чистое» выравнивание без висячих гэпов в конце w. Если взять первый j (с `>`), могут появиться лишние пробелы в правом конце w-строки.

**Свободный префикс v в backtrack:** когда j достигает 0, в стеке могут остаться символы v (i > 0). Это бесплатный префикс v — мы его НЕ добавляем в alignV/alignW, просто выходим из цикла. Именно поэтому нет `while(i > 0)` в конце.

## Запуск

```bash
./ba5i-overlap_alignment                              # sample
./ba5i-overlap_alignment --input rosalind_ba5i.txt   # Rosalind вход
./ba5i-overlap_alignment -i rosalind_ba5i.txt -o out.txt
```

## Анализ сложности

**Время: O(n·m)** — двойной цикл заполнения матрицы (функция `overlapAlignment`).  
**Память: O(n·m)** — полная матрица dp для backtrack. Узкое место: вложенный `for i... for j` в `overlapAlignment`.
