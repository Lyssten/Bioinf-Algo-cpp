# Local Alignment (BA5F)

## Задача

Найти наилучшее **локальное** выравнивание двух аминокислотных последовательностей — то есть найти такие подстроки v' из v и w' из w, выравнивание которых даёт максимальный суммарный счёт.

**Вход:** две строки аминокислот (одна буква = одна аминокислота)
**Выход:** максимальный счёт; две выровненные подстроки с символами `-` на месте пропусков

Формат входного файла Rosalind:
```
MEANLY
PENALTY
```

**Пример:**
```
Вход:       Вывод:
MEANLY      15
PENALTY     EANL-Y
            ENALTY
```

Счёт проверяем вручную по выравниванию `EANL-Y / ENALTY`:
- E vs E: PAM250(E,E) = 4
- A vs N: PAM250(A,N) = 0
- N vs A: PAM250(N,A) = 0
- L vs L: PAM250(L,L) = 6
- `-` vs T: штраф за гэп = -5
- Y vs Y: PAM250(Y,Y) = 10
- Итого: 4 + 0 + 0 + 6 - 5 + 10 = **15** ✓

## Обозначения

| Имя | Что это |
|-----|---------|
| `v` | первая входная строка (аминокислоты); в DP соответствует **строкам** матрицы |
| `w` | вторая входная строка; соответствует **столбцам** матрицы |
| `n` | длина v (`v.size()`) |
| `m` | длина w (`w.size()`) |
| `dp[i][j]` | таблица динамического программирования; значение — лучший локальный счёт выравнивания, заканчивающегося на `v[i-1]` и `w[j-1]` (индекс в матрице на 1 больше, чем в строке) |
| `sigma` | штраф за один символ гэпа (`-` в выравнивании); здесь = 5 |
| `diag` | счёт при диагональном шаге: `v[i-1]` выровнен с `w[j-1]` |
| `up` | счёт при шаге вверх: `v[i-1]` выровнен с `-` (пропуск в w) |
| `left` | счёт при шаге влево: `-` выровнено с `w[j-1]` (пропуск в v) |
| `bestScore` | максимальное найденное значение в матрице dp |
| `bestI`, `bestJ` | строка и столбец ячейки с `bestScore`; отсюда начинается backtrack |
| `alignV` | строка выравнивания для v (строится в обратном порядке) |
| `alignW` | строка выравнивания для w (строится в обратном порядке) |
| **backtrack** | процесс восстановления выравнивания: идём по уже заполненной матрице DP **в обратном направлении** от конечной ячейки к начальной, на каждом шаге определяя, откуда пришли (диагональ, вверх или влево) |
| **DP** | динамическое программирование (dynamic programming) — метод решения задачи через разбивку на перекрывающиеся подзадачи, результаты которых сохраняются в таблице |

## Теория

### Локальное vs глобальное выравнивание

**Глобальное выравнивание** (Нидлман–Вунш) сравнивает обе последовательности целиком от начала до конца. Это хорошо работает, когда белки схожи на всём протяжении.

**Локальное выравнивание** (Смит–Уотерман, 1981) ищет только наиболее похожие фрагменты внутри последовательностей. Это полезно, когда два белка имеют лишь один общий домен, а остальные участки совершенно разные.

Пример: у вируса гриппа и у человека разные белки, но оба содержат небольшой РНК-связывающий мотив. Локальное выравнивание найдёт именно этот общий фрагмент и проигнорирует «шумные» края.

### Матрица PAM250

**PAM** расшифровывается как Percent Accepted Mutation. Матрица PAM250 описывает вероятности замен аминокислот за 250 эволюционных шагов (~20% идентичности).

Каждая клетка PAM250[a][b] — это логарифм отношения:
```
log( вероятность наблюдать замену a→b / вероятность случайной встречи a и b )
```

Положительное значение: замена встречается чаще случайного (биологически консервативная). Отрицательное: замена редкая (биологически нежелательная). Например:
- L (лейцин) ↔ M (метионин): 4 — оба гидрофобные, легко заменяют друг друга
- W (триптофан) ↔ G (глицин): -7 — W крупный ароматический, G простейший; замена маловероятна

В коде матрица хранится как `static const int PAM250[20][20]` — двумерный массив 20×20, по одной строке/столбцу на каждую из 20 стандартных аминокислот. Аминокислоты упорядочены **алфавитно** по однобуквенному коду: `ACDEFGHIKLMNPQRSTVWY`.

### Ключевая идея: ноль как «перезапуск»

В глобальном выравнивании каждая ячейка dp[i][j] берётся из одного из трёх предшественников. В локальном добавляется четвёртый вариант — **0**:

```
dp[i][j] = max( 0,
                dp[i-1][j-1] + score(v[i], w[j]),   // диагональ: совпадение
                dp[i-1][j]   - sigma,                // вверх: пропуск в w
                dp[i][j-1]   - sigma )               // влево: пропуск в v
```

Если все три предшественника дают отрицательный результат, ячейка обнуляется. Это означает: «не продолжать плохое выравнивание, лучше начать заново». Именно из-за этого нуля алгоритм называется **Smith-Waterman**, а не Needleman-Wunsch.

### Как найти выравнивание

Заполнив матрицу, ищем ячейку с максимальным значением — это конец оптимального локального выравнивания. Затем идём назад по матрице (backtrack), пока не попадём в ячейку со значением **0** — это начало выравнивания.

## Применение

**BLAST** (NCBI) — самый используемый инструмент биоинформатики. Ищет похожие последовательности в базах данных (GenBank, UniProt). Внутри использует эвристику на основе идей локального выравнивания: находит «зёрна» (короткие точные совпадения), а затем расширяет их методом, похожим на Smith-Waterman.

**EMBOSS Water** — точная реализация Smith-Waterman для сравнения двух конкретных белков, когда нужна биологически корректная интерпретация каждого гэпа.

## Алгоритм

**Шаг 1 — заполнение матрицы:**
```
Инициализация: dp[0][j] = 0, dp[i][0] = 0  (граничные условия)

for i = 1..n:                               (проходим по строкам, символы v)
    for j = 1..m:                           (проходим по столбцам, символы w)
        diag = dp[i-1][j-1] + PAM250[v[i]][w[j]]
        up   = dp[i-1][j]   - sigma
        left = dp[i][j-1]   - sigma
        dp[i][j] = max(0, diag, up, left)
        если dp[i][j] > bestScore:
            обновить bestScore, bestI, bestJ
```

**Шаг 2 — backtrack (восстановление пути):**
```
i = bestI, j = bestJ
пока dp[i][j] != 0:
    если dp[i][j] == dp[i-1][j-1] + score(v[i], w[j]):
        добавить v[i] и w[j] в alignV, alignW
        i--, j--
    иначе если dp[i][j] == dp[i-1][j] - sigma:
        добавить v[i] в alignV, '-' в alignW
        i--
    иначе:
        добавить '-' в alignV, w[j] в alignW
        j--
перевернуть alignV и alignW
```

## Реализация на C++

Ключевые части функции `localAlignment`:

```cpp
// 1. n и m — длины строк. Нужны для размеров матрицы и границ цикла.
int n = static_cast<int>(v.size());
int m = static_cast<int>(w.size());

// 2. dp — матрица (n+1)×(m+1). Индексация начинается с 0:
//    dp[0][*] и dp[*][0] — граничные условия, уже равны 0 по умолчанию.
//    dp[i][j] (i,j >= 1) — лучший локальный счёт, если выравнивание
//    заканчивается на символах v[i-1] и w[j-1].
std::vector<std::vector<int>> dp(n + 1, std::vector<int>(m + 1, 0));

// 3. bestScore, bestI, bestJ — координаты ячейки с максимальным значением.
//    Именно из неё начинается backtrack (в отличие от глобального
//    выравнивания, где всегда стартуем из правого нижнего угла).
int bestScore = 0;
int bestI = 0, bestJ = 0;

for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        // 4. diag — счёт при совпадении/замене: берём ячейку по диагонали
        //    и прибавляем вес из PAM250. score() вызывает aaIndex() для
        //    получения индексов и смотрит в PAM250[idx_a][idx_b].
        int diag = dp[i-1][j-1] + score(v[i-1], w[j-1]);
        // 5. up — счёт при пропуске символа w (ребро «вверх» в матрице):
        //    уходим из строки i-1 без продвижения в w.
        int up   = dp[i-1][j]   - sigma;
        // 6. left — счёт при пропуске символа v (ребро «влево»):
        //    уходим из столбца j-1 без продвижения в v.
        int left = dp[i][j-1]   - sigma;

        // 7. std::max({0, diag, up, left}) — перегрузка max для
        //    initializer_list из <algorithm>. Ноль — это «перезапуск»:
        //    если все три варианта отрицательны, начинаем заново.
        dp[i][j] = std::max({0, diag, up, left});

        // 8. Отслеживаем максимум по всей матрице.
        //    > (строгое), а не >= : при равных значениях оставляем первый
        //    найденный максимум.
        if (dp[i][j] > bestScore) {
            bestScore = dp[i][j];
            bestI = i;
            bestJ = j;
        }
    }
}

// 9. Backtrack. Переменные i, j — текущая позиция при обходе назад.
//    Строки alignV и alignW накапливают символы выравнивания В ОБРАТНОМ порядке.
std::string alignV, alignW;
int i = bestI, j = bestJ;

// 10. Условие остановки — dp[i][j] == 0. Это значит, что мы дошли
//     до начала локального совпадения (откуда берётся «свободный старт»).
//     Также проверяем i > 0 && j > 0, чтобы не выйти за границы матрицы.
while (i > 0 && j > 0 && dp[i][j] != 0) {
    if (dp[i][j] == dp[i-1][j-1] + score(v[i-1], w[j-1])) {
        // 11. Диагональный шаг: оба символа вошли в выравнивание.
        //     v[i-1] и w[j-1] — это i-й и j-й символы (0-индекс),
        //     соответствующие строке i и столбцу j матрицы.
        alignV += v[i-1];
        alignW += w[j-1];
        --i; --j;
    } else if (dp[i][j] == dp[i-1][j] - sigma) {
        // 12. Шаг «вверх»: в v есть символ, в w — пропуск.
        alignV += v[i-1];
        alignW += '-';
        --i;
    } else {
        // 13. Шаг «влево»: в w есть символ, в v — пропуск.
        alignV += '-';
        alignW += w[j-1];
        --j;
    }
}

// 14. Строки собраны задом наперёд (мы шли от конца к началу).
//     std::reverse переворачивает их на месте.
std::reverse(alignV.begin(), alignV.end());
std::reverse(alignW.begin(), alignW.end());
```

## Разбор кода

**`aaIndex(char c)`** — вспомогательная функция. Принимает букву аминокислоты (`'A'`, `'W'`, и т.д.) и возвращает её индекс (0–19) в строке `AA_ALPHA = "ACDEFGHIKLMNPQRSTVWY"`. Используется для обращения к PAM250. Если символ не найден (`std::string::npos`) — бросает исключение, что позволяет поймать ошибку ввода.

**`score(char a, char b)`** — обёртка над PAM250. Переводит два символа в индексы и возвращает `PAM250[idx_a][idx_b]`. Вынесена отдельно, чтобы не засорять основной цикл.

**`struct Alignment`** — объединяет три значения результата (`score`, `alignedV`, `alignedW`) в один объект. Без этой структуры пришлось бы возвращать их через out-параметры или `std::tuple`. Структура возвращается по значению, компилятор оптимизирует это через RVO (Return Value Optimization).

**Почему `static_cast<int>(v.size())`?** — `v.size()` возвращает `size_t` (беззнаковый тип). При вычитании `--i` беззнаковый 0 превратился бы в гигантское положительное число. `static_cast<int>` переводит в знаковый int, где `i > 0` работает корректно.

**Порядок проверки в backtrack:** сначала диагональ, потом вверх, потом влево. Это конкретная политика разрешения ничьей — при равных значениях предшественников выбирается диагональ. Это влияет на конкретный вид выравнивания, но не на его счёт.

**`std::vector<std::vector<int>>`** — матрица размером `(n+1) × (m+1)`. Все ячейки инициализируются 0 (второй аргумент конструктора `std::vector`), что задаёт граничные условия автоматически.

## Запуск

```bash
# Без аргументов — встроенный пример MEANLY/PENALTY
./ba5f-local_alignment

# Файл с Rosalind (вывод сохраняется рядом с вводом как .out)
./ba5f-local_alignment --input rosalind_ba5f.txt

# Явно задать выходной файл
./ba5f-local_alignment --input rosalind_ba5f.txt --output result.txt

# Короткие флаги
./ba5f-local_alignment -i rosalind_ba5f.txt -o result.txt
```

## Анализ сложности

**Время: O(n * m)** — два вложенных цикла, каждая итерация выполняет фиксированное число операций: 3 сложения, 1 вызов `score()`, 1 вызов `std::max`. Узкое место — строки 62–73 в `localAlignment` (двойной цикл `for i for j`).

**Память: O(n * m)** — матрица `dp` хранится целиком, потому что backtrack требует доступа к любой ячейке. Для строк длиной 1000 а.к. это 1000 × 1000 × 4 байта = ~4 МБ. Для очень длинных последовательностей (>50 000 а.к.) потребовалась бы оптимизация памяти — но для этого существует BA5L (Hirschberg).
