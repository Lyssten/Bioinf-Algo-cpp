# Middle Edge in Linear Space (BA5K)

## Задача

Найти среднее ребро в графе выравнивания — первый шаг алгоритма Хиршберга для глобального выравнивания в линейной памяти.

**Вход:** два пептида  
**Выход:** координаты ребра в формате `(r1, c1) (r2, c2)`

Формат входного файла Rosalind:
```
PLEASANTLY
MEANLY
```

**Пример:**
```
Вход:
PLEASANTLY
MEANLY

Вывод:
(6, 3) (7, 4)
```

Используется BLOSUM62, штраф за гэп σ=5.

## Теория

### Зачем нужно среднее ребро

Стандартный алгоритм глобального выравнивания требует O(n·m) памяти для хранения всей DP-матрицы (backtrack). Для белков длиной 1000 а.к. это ≈4 МБ, для 10 000 — уже 400 МБ.

**Алгоритм Хиршберга (1975)** вычисляет оптимальное выравнивание за O(n+m) памяти, рекурсивно разбивая задачу. Ключевой шаг — нахождение ребра, проходящего через середину матрицы по второму измерению.

### Как найти среднее ребро

Пусть mid = ⌊|w|/2⌋ — средний столбец матрицы выравнивания.

1. **from_source[i]** = лучший score пути от (0,0) до (i, mid)  
   → вычисляется стандартным DP, но только до столбца mid (O(n·mid) памяти, но мы оставляем только последний столбец)

2. **to_sink[i]** = лучший score пути от (i, mid+1) до (n, m)  
   → вычисляется DP на **обращённых** строках v_rev и (w[mid+1..m-1])_rev

3. Перебираем все возможные рёбра, пересекающие середину:
   - **Диагональное** (i, mid) → (i+1, mid+1): `from_source[i] + BLOSUM62(v[i], w[mid]) + to_sink[i+1]`
   - **Горизонтальное** (i, mid) → (i, mid+1): `from_source[i] − σ + to_sink[i]`

Выбираем ребро с максимальной суммарной оценкой.

### Почему обращение строк работает

Score глобального выравнивания не изменяется при обращении обеих строк (симметрия). Поэтому вместо «от (i, mid+1) до (n, m)» вычисляем «от (0, 0) до (n−i, m−mid−1)» на обращённых строках — обычный forward DP.

## Применение

Среднее ребро является строительным блоком алгоритма **Хиршберга**, который лежит в основе выравнивателей с экономным использованием памяти. Пакет **diff** в Unix (для сравнения текстовых файлов) реализует родственный алгоритм. В биоинформатике алгоритм Хиршберга встроен в EMBOSS Needle и другие точные глобальные выравниватели.

## Алгоритм

**Идея:** разделяй и властвуй по средней колонке.

**Псевдокод:**
```
mid = |w| / 2

# Прямой DP (left half): только последний столбец
fromSrc[0..n] = alignColumn(v, w[0..mid-1])  // O(n·mid) время, O(n) память

# Обратный DP (right half): обращаем обе строки
vRev = reverse(v)
wSufRev = reverse(w[mid+1..m-1])
revCol[0..n] = alignColumn(vRev, wSufRev)  // O(n·(m-mid-1)) время
toSink[i] = revCol[n-i]

# Перебор рёбер через середину
bestScore = -∞
for i in 0..n:
    checkHoriz: from[i] - σ + toSink[i]
    checkDiag:  from[i] + BLOSUM(v[i], w[mid]) + toSink[i+1]
```

## Реализация на C++

```cpp
// 1. Вспомогательная функция: DP до столбца targetCol, возвращает колонку
static std::vector<int> alignColumn(const string& v, const string& w,
                                    int sigma, int targetCol) {
    vector<int> prev(n+1), curr(n+1);
    for (int i=0;i<=n;++i) prev[i]=-i*sigma; // 2. инициализация

    for (int j=1;j<=targetCol;++j) { // 3. только нужные столбцы
        curr[0]=-j*sigma;
        for (int i=1;i<=n;++i)
            curr[i]=max({prev[i-1]+blosum(v[i-1],w[j-1]), prev[i]-sigma, curr[i-1]-sigma});
        swap(prev, curr); // 4. O(n) память: храним только два столбца
    }
    return prev;
}

// 5. Обратный DP: обращение строк
string vRev(v.rbegin(), v.rend());
string wSufRev(w.rbegin(), w.rbegin() + (m-mid-1)); // reverse(w[mid+1..m-1])
auto revCol = alignColumn(vRev, wSufRev, sigma, wSufRev.size());
// to_sink[i] = revCol[n-i]
```

## Разбор кода

**`std::swap(prev, curr)`** позволяет работать только с двумя векторами вместо всей матрицы. После k-й итерации `prev` содержит k-й столбец DP. Это O(n) памяти против O(n·m) для полной матрицы.

**`w.rbegin(), w.rbegin() + k`:** `rbegin()` — обратный итератор, указывающий на последний символ. `rbegin() + k` берёт k первых символов с конца строки w. Так строится обращённый суффикс без копирования.

**Инициализация bestScore = NEG_INF:** `std::numeric_limits<int>::min() / 2` — безопасное отрицательное бесконечное значение. Деление на 2 защищает от переполнения при вычитании sigma.

## Запуск

```bash
./ba5k-middle_edge                              # sample: PLEASANTLY/MEANLY
./ba5k-middle_edge --input rosalind_ba5k.txt   # Rosalind вход
./ba5k-middle_edge -i in.txt -o out.txt
```

## Анализ сложности

**Время: O(n·m)** — прямой и обратный DP суммарно проходят все клетки матрицы.  
**Память: O(n+m)** — ключевое достоинство: функция `alignColumn` хранит только два вектора длиной n+1, а не всю матрицу. Узкое место: `for j ... for i` внутри `alignColumn` (два вызова).
