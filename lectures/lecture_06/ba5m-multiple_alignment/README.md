# Multiple Sequence Alignment (BA5M)

## Задача

Найти наилучшее множественное выравнивание трёх строк, максимизируя число столбцов, где все три символа совпадают.

**Вход:** три строки  
**Выход:** счёт; три выровненные строки

Формат входного файла Rosalind:
```
ATATCCG
TCCGA
ATGTACTG
```

**Пример:**
```
Вход:
ATATCCG
TCCGA
ATGTACTG

Вывод:
3
AT-ATCCG-
-T---CCGA
ATGTACTG-
```

match=1 (все три одинаковы), иначе 0 (гэп без штрафа).

## Теория

### Обобщение попарного выравнивания на k строк

Для двух строк DP работает в 2D-матрице с 3 типами рёбер. Для трёх строк задача расширяется на 3D-куб с 7 типами рёбер (2³−1 = 7: все способы продвинуться хотя бы по одному измерению).

```
Из ячейки (i, j, k) в ячейку (i+d1, j+d2, k+d3), где (d1,d2,d3) ≠ (0,0,0):
  • (1,1,1): все три строки — совпадение/несовпадение
  • (1,1,0): v1 и v2 совпадают, v3 получает гэп
  • (1,0,1): v1 и v3, v2 — гэп
  • (0,1,1): v2 и v3, v1 — гэп
  • (1,0,0): только v1, остальные — гэп
  • (0,1,0): только v2
  • (0,0,1): только v3
```

Из-за экспоненциального роста рёбер (2^k − 1) множественное выравнивание NP-трудно для k → ∞. Для k=3 O(n³) вполне приемлемо.

### Функция оценки

В этой задаче score(column) = 1 если все три символа не-гэп и одинаковы, иначе 0. Нет штрафа за гэпы. DP-значения монотонно неубывают.

### Инициализация

При отсутствии штрафов за гэпы все dp-значения ≥ 0, начальное значение 0. Нет необходимости в особой инициализации краёв куба — они автоматически равны 0 (нет совпадений при выравнивании с пустой строкой).

## Применение

**MAFFT** и **Clustal Omega** — современные инструменты для множественного выравнивания белков. Они используют более сложные эвристики (progressive alignment, profile-profile), но концептуально основаны на той же идее 3D-DP.

Множественное выравнивание — основа для построения филогенетических деревьев, поиска консервативных позиций в семействах белков, и дизайна ПЦР-праймеров.

## Алгоритм

**Идея:** 3D динамическое программирование, где dp[i][j][k] = максимальное число полных совпадений при выравнивании v1[0..i-1], v2[0..j-1], v3[0..k-1].

**Псевдокод:**
```
dp[0][0][0] = 0

for i in 0..n1, j in 0..n2, k in 0..n3 (за исключением (0,0,0)):
  s = 1 если i>0 && j>0 && k>0 && v1[i-1]==v2[j-1]==v3[k-1] else 0
  
  candidates = [
    dp[i-1][j-1][k-1]+s  если i,j,k>0      // (1,1,1)
    dp[i-1][j-1][k]       если i,j>0        // (1,1,0)
    dp[i-1][j  ][k-1]     если i,k>0        // (1,0,1)
    dp[i  ][j-1][k-1]     если j,k>0        // (0,1,1)
    dp[i-1][j  ][k  ]     если i>0          // (1,0,0)
    dp[i  ][j-1][k  ]     если j>0          // (0,1,0)
    dp[i  ][j  ][k-1]     если k>0          // (0,0,1)
  ]
  dp[i][j][k] = max(candidates)

Ответ: dp[n1][n2][n3]
```

## Реализация на C++

```cpp
// 1. 3D массивы для DP и backtrack
vector<vector<vector<int>>> dp(n1+1, ...);
vector<vector<vector<int8_t>>> back(n1+1, ...); // биты: d1d2d3

for (int i=0;i<=n1;++i) for (int j=0;j<=n2;++j) for (int k=0;k<=n3;++k) {
    int best = NEG_INF; int8_t bestDir = 0;
    
    // 2. Лямбда-обновление: 7 предшественников
    auto tryUpdate = [&](int pi,int pj,int pk, int8_t dir, int add) {
        int val = dp[pi][pj][pk] + add;
        if (val > best) { best=val; bestDir=dir; }
    };
    
    if (i>0&&j>0&&k>0) {
        int s = (v1[i-1]==v2[j-1]&&v2[j-1]==v3[k-1]) ? 1 : 0;
        tryUpdate(i-1,j-1,k-1, 7, s); // 3. 7 = 0b111
    }
    // ... ещё 6 вариантов ...
    back[i][j][k] = bestDir;
}

// 4. Backtrack: читаем биты направления
int i=n1, j=n2, k=n3;
while (i>0||j>0||k>0) {
    int8_t dir = back[i][j][k];
    int d1=(dir>>2)&1, d2=(dir>>1)&1, d3=(dir>>0)&1; // 5. битовые маски
    a1 += (d1 ? v1[i-1] : '-');
    a2 += (d2 ? v2[j-1] : '-');
    a3 += (d3 ? v3[k-1] : '-');
    i-=d1; j-=d2; k-=d3;
}
```

## Разбор кода

**`int8_t back[i][j][k]`:** кодирует направление тремя битами. Бит 2 (старший из трёх): двигалась ли v1, бит 1: v2, бит 0: v3. Значения: 7=111 (все три), 6=110, 5=101, 3=011, 4=100, 2=010, 1=001.

**`(dir >> 2) & 1`:** сдвиг вправо на 2 позиции, затем AND с 1 даёт старший бит из трёх.

**Лямбда `tryUpdate`:** захватывает `best` и `bestDir` по ссылке. Обновляет только при строгом улучшении (>). Начальное `best = NEG_INF` гарантирует, что первый валидный предшественник всегда принимается.

**3D-вектор:** `vector<vector<vector<int>>>` проще 3D-массива по размеру. Для строк длиной ≤500 память составит 500³×4 байта ≈ 500 МБ — нужна осторожность. Для типичных Rosalind-входов (10–50 символов) это несколько килобайт.

## Запуск

```bash
./ba5m-multiple_alignment                              # sample
./ba5m-multiple_alignment --input rosalind_ba5m.txt   # Rosalind вход
./ba5m-multiple_alignment -i in.txt -o out.txt
```

## Анализ сложности

**Время: O(n1·n2·n3)** — тройной вложенный цикл с O(1) работой на каждой ячейке (7 предшественников — константа). Узкое место: тройной цикл `for i... for j... for k` в функции `multipleAlignment`.  
**Память: O(n1·n2·n3)** — 3D-массивы dp и back. При длинах строк >200 может потребовать несколько гигабайт. В Rosalind типичные строки короткие (≤50 символов), память не проблема.
